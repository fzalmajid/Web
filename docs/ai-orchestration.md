# AI Ruang Belajar orchestration

The normal chat surface now exposes experience depth instead of a model picker:

- `Simple`: browser/local retrieval only. No cloud provider is required.
- `Instant`: one provider response after the existing Hybrid RAG and source checks.
- `Medium`: planner, Database/scholarly researcher, independent tutor, and final synthesizer.
- `High`: planner → Web/Database/scholarly research → three reasoning roles → verifier → critic → final synthesizer.

`Choose Model` remains available under the explicit Debug disclosure so provider/model failures can still be reproduced without making model selection part of the normal user experience.

## Optional server integrations

The app is deployable without these variables. If they are absent, the existing provider Web grounding remains the fallback.

| Variable | Purpose |
| --- | --- |
| `SEARXNG_URL` | SearXNG base URL, used for public search results. |
| `CRAWL4AI_URL` | Crawl4AI base URL, used to fetch and clean top result pages. |
| `OPENROUTER_API_KEY` | Optional helper-agent key. |
| `OPENROUTER_FREE_MODEL` | Optional OpenRouter model. The app only accepts values ending in `:free`. |

The status endpoint reports whether these adapters are configured. SearXNG/Crawl4AI are intentionally adapters, not hard dependencies on a fragile public endpoint. A configured Crawl4AI endpoint is tried first for page cleaning, then the server falls back to a direct public fetch, then the existing provider Web path remains available.

## Browser Record pipeline

Record keeps WebRTC `echoCancellation`, `noiseSuppression`, and `autoGainControl` enabled. After Stop, the browser tries Silero VAD to remove long silence/noise segments and then sends the remaining audio to an isolated Transformers.js Whisper worker. Device probing uses WebGPU first and falls back to WASM; it selects Tiny, Base, or Small conservatively and keeps model weights in the browser cache. If local assets, model download, decoding, or inference fail, the existing browser transcript/provider transcription path is preserved.

The checked-in `/public/vad` assets are generated by `npm run prepare:vad-assets` from `@ricky0123/vad-web` and `onnxruntime-web`. The VAD wrapper is ISC licensed and ONNX Runtime Web is MIT licensed. Whisper is the OpenAI model family; the upstream Whisper software license is retained by the model source.

## Local helper

Medium and High send a small advisory helper payload. If the existing LM Studio/Ollama/OpenAI-compatible local plugin is connected, the helper uses that endpoint for intent classification, query rewrite, and source terms. Otherwise it uses a deterministic browser heuristic. The payload is advisory only and cannot create citations or replace Database/Web evidence.
